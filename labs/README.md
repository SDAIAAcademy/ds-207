# Responsible Data Practice and Conduct in Analytical Work: labs

Twelve labs of 25 minutes on one case: the Student Success Unit of Al-Qimam University, a
fictional public university, and its referral rule Awn. All data is synthetic and is generated by
`prepare_data.py` with a fixed seed. No lab calls a model or needs an account or a key: the labs
use Python and pandas only, on a laptop or in Google Colab.

## Quick start

- Google Colab: open a notebook from the table; its first cell clones this repository.
- Locally: clone the repository, then from `labs/` run `uv sync` and `uv run jupyter lab`.
  Run `00_setup_check.ipynb` first.

## How the labs work

- Every lab starts from files supplied in `data/`, never from the result of an earlier lab. A
  participant who missed a session can start any lab.
- Each exercise is a function to complete. If it is left unfinished, the next cell loads the
  expected result from `data/reference/`, so the rest of the notebook still runs.
- The completed notebooks are in `solutions/`. `solutions/answer_key.md` lists what is planted in
  the data and the numbers a trainer should expect; `solutions/keys.json` holds the keys of the
  Day 1 decisions and of the capstone data.
- Labs write their results to `artifacts/`, which is not committed.
- Labs 3.2 and 3.3 are role-plays in groups of three. They are done without an AI assistant, and
  the trainer runs the timers on the slides.

## The data

| File | What it is |
|---|---|
| `data/students.csv` | 18,000 synthetic student records, 30 columns, with free-text advisor notes |
| `data/analysis_extract.csv` | The pseudonymised extract used from Day 2 on |
| `data/roll_call_audit.csv` | A hand roll call used to check the attendance record |
| `data/privacy_notice.md`, `data/release_policy.md` | The University's notice to students and the unit's release policy (threshold of 10) |
| `data/*.json` | The requests, briefs, templates and pipeline descriptions the labs read |
| `capstone/` | Three engagements of 4,000 records each, and the pack template |

To regenerate everything: `uv run python prepare_data.py`, then
`uv run python _tools/make_reference.py`.

The threshold of 10 for small cells is the fictional University's own policy. The national
instruments require that released statistics do not identify a person; they do not set a number.

## Tools named and not installed

The course names Fairlearn, DuckDB, Microsoft Presidio and Quarto where they fit. The labs do
not install them: every computation is a few lines of pandas, so that the rule being applied
stays visible.

## The capstone and the follow-up task

`capstone/README.md` describes the three engagements, the six documents of the pack, the rubric
and the eight-minute defence.

**Follow-up task, within four weeks of the course.** For one dataset you work with, write a
one-page classification and sharing table: the dataset and its owner; its classification level
and the reason; the fields that are personal or sensitive; who may receive it, in what form and
under which conditions; and what it must not be used for. Agree it with the data owner and send
it to the trainer with the owner's confirmation. Do not include any real records.

## Editing the labs

The notebooks are generated from the percent-format sources in `labs/_src/` by
`labs/_tools/py2nb.py` (`uv run python _tools/py2nb.py` from `labs/`), which also writes the
solutions to `labs/solutions/`. Edit the sources, not the notebooks.
